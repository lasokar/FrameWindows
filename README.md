# Frame Windows
This mod measures and displays a level's frame windows as you play in real time. Should help make the counting process a lot less tedious! I recommend disabling CBF and CBS when using this, but it's not needed.

## Features
- Works with all classic gamemodes (though non-flying ones are the most accurate).
- Macro/xdBot playback support.
- Toggleable counters.
- Can measure up to 240 frame clicks.

<cr>This is **NOT** an "Auto Frame Counter" and is not meant to be used for professional Frame Counter showcases or videos. Because this mod measures frame windows in real time rather than from a predetermined macro, it will likely never be as accurate as manual counting.</c>
